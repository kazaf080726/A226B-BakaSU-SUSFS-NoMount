## Quick start

1. Download: [Releases](https://github.com/kazaf080726/A226B-BakaSU-SUSFS-NoMount/releases)
2. Back up the stock boot image
3. Flash `A226B-BakaSU-SUSFS-NoMount-*.zip` in TWRP
4. Install the BakaSU manager

Details are in section 5 of [README.en.md](../../README.en.md).

## Maintenance convention

When editing a document, **update both languages** and keep the numbers (hashes, line counts, file names)
identical — a stale hash in one language is worse than no hash at all.
